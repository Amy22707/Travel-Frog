# 旅行青蛙·中国之旅

《旅行青蛙·中国之旅》的非官方离线版。可以在 Windows、安卓和网页上继续养蛙、准备行囊、收明信片。进度保存在当前设备，可以通过存档文件换设备。

## 选择版本

| 版本 | 玩法 |
| --- | --- |
| 普通版 | 从新手开始，或导入自己的存档。按游戏进度解锁物品，购买与使用时按规则消耗库存。 |
| 图鉴版 | 使用独立存档，预先解锁地图、旅行装备、家具、故事、称号、友情绘本和图鉴等收藏。常用消耗品与货币保持固定数量，中秋、新年和周年庆活动可随时体验。 |

两版都包含旅行、相册与动态照片、花圃、家具、手工品、旅友来访和周末的小插曲。离线版将漂流瓶入口改为本地旅行日记，真人社交和排行榜需要官服。

## 安装与游玩

- **Windows**：从下载页取得 `TravelFrogSetup.exe`，双击选择版本。安装器会下载所选版本，也可使用放在同一文件夹的对应 Windows 压缩包。安装后，普通版和图鉴版分别通过 `FrogNormal.exe` 和 `FrogGallery.exe` 打开。游戏使用本机 Edge 或 Chrome，无需模拟器或 Python。
- **安卓**：安装普通版 `FrogNormal.apk` 或图鉴版 `FrogGallery.apk`。打开后创建或导入存档即可游玩，两版可以同时安装。
- **网页与 iPhone / iPad**：用浏览器打开网页入口，选择版本，然后创建或导入存档。iPhone 和 iPad 可以在 Safari 通过“分享 → 添加到主屏幕”安装网页应用。需要断网游玩时，在网页起始页下载离线资源。

## 转移存档

在旧设备导出 `.frogsave`，在新设备打开同一版本并导入。导入会备份被覆盖的进度。照片图层和旅行日记随存档迁移。请先导出存档，再卸载应用、清理浏览器数据或替换程序目录。

已有官服备份可以导入普通版。只有官服账号时，需要在仍可正常登录的设备上采集自己的完整登录数据，才能制作备份。原始日志和存档含个人数据，请保存在自己的设备上。
