# 系统接入检查

2026-11-03，重点检查有正式客户端入口、处理代码或配置但未接到运行流程的系统。

## 庭院串门

已接入普通版、图鉴版的共享登录同步流程；Windows 服务、安卓本机运行和网页/PWA 使用同一实现。来访、吃饭动作、到期回礼、省花首次收录和后续奖励均沿用正式客户端的数据格式。间隔随机 2–5 天，停留随机 20–60 分钟，属于本地规则。

来访与未领取回礼在存档中保存，不受重启影响，不消耗礼品盒内容。原有 `advance_giftbox_social` 属于早期错误地将礼品盒连接到省花的遗留函数，仍不接入；新的庭院旅蛙使用独立调度。

## 周末的小插曲

北京时间每周六 00:00 开放、周一 00:00 关闭，下个周六起结算本周提交的五个选项。正式客户端的 `LotteryModel.getLeftTime` 只在周六、周日显示倒计时；2026-09-12 抓包记录第 171 期提交，2026-09-19 00:26 抓包记录领取第 171 期回礼并开始第 172 期。周六零点作为换期边界与两者吻合，抓包未观测到换期的精确秒点。

每周在登录同步时推进期数，候选、提交答案和待领取结果保留在各自存档中。错过几周也保留已提交的答谢，领取后进入当前期，不补发错过的参与奖励。答谢进入邮箱，同一期只发一次。活动按原客户端四周轮换小伙伴，嘟嘟期使用植物题；已抓取结果保留。其他期的正确选项从当期候选中抽取五个，回礼为 10 加每个命中 10 枚三叶草，另按命中数送最多三张抽奖券；这是离线规则，不是官服算法。

## 离线版的差异

- **漂流瓶**：入口改为本地旅行日记，可以记录自己的旅行；不接收或发送其他玩家的漂流瓶。
- **排行榜**：离线版不提供真实玩家排行榜。

## 已接入但应持续验收

普通新档的小仓库按客户端条件显示入口。手工品工具与友情绘本可在商店购买，家具入口由商店状态开放，旅行百科按实际携带物品的旅行结算开放（含编号 0 的基础便当）。动态照片在相册首次拥有正式配置中可制作的照片后，于下次进游戏开启原引导；这是离线解锁条件。

普通空白档的首条见闻与后续见闻使用同一个返程掉落流程：从未收录、满足配置前置条件的正式见闻中取一个候选，按其掉落参数进行一次本地判定；首条取得后小仓库显示见闻入口。每次返程抽取一个候选是离线规则。已认识旅友可通过礼品盒回赠取得笔记；空白档的旅友初遇笔记仍是另一条未闭环路径。

旅行、聚会返程、礼品盒旅友赠礼、庭院邻居、花圃、花瓶、家具和手工品均有运行调用点。存档中的旧 unknown_commands 日志含若干历史未实现记录，当前已存在对应处理，不能仅凭旧日志判断今天仍未实现。

本轮以调用关系、登录协议和客户端实际消费为检查范围，不代表逐一验收所有历史玩法概率。未知官服概率与后续功能按独立任务继续处理。
